# Release notes

## v1.2.0-submission

This release aligns the public reproducibility package with the temporal-observability manuscript revision.

Changes since v1.1.0:

- reframed the primary analysis around episode-level temporal observability and decision-opportunity metrics;
- added duration, severity, threshold, and sampling-interval analyses;
- added exploratory creatinine-defined AKI association models, including incremental adjustment for total reference hypotension burden;
- added a prespecified-gate exploratory ICU length-of-stay resource-use analysis;
- added independent R checks for the principal AKI and ICU models;
- replaced all aggregate tables, figure source data, figures, workbook, and integrity manifests with the current frozen outputs;
- synchronized creator metadata with the current author group;
- retained a strict redistribution boundary excluding source datasets and patient-level derivatives.

The package does not estimate a causal effect of monitoring frequency on management or postoperative outcomes.
