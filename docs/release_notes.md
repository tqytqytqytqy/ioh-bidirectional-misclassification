# v1.5.0

This release contains analysis code, configuration templates, reproducibility
manifests, figure source data, the final workbook, editable scientific figures
and non-identifiable aggregate outputs.

Raw VitalDB, MoVeR and INSPIRE datasets are not redistributed. Source recordings,
case-level derivatives, private configuration, manuscript files and internal
case-review materials are excluded.

The release retains original analyses and completed algorithmic startup-QC
sensitivities, presents 4 main tables and 16 supplementary tables, and includes
the latest manuscript-matched scientific artwork. Release assembly does not
refit models or execute new source-data analyses. Independent physician clinical
adjudication was not performed.

Jing Zhao replaces Tao Xu in the current creator list. We thank Tao Xu for his guidance and comments on this study.
Historical releases and their creators are preserved.
