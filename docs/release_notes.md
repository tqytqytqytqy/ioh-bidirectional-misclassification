# Release notes: v1.1.0-submission

This release contains analysis code, configuration templates, reproducibility manifests, figure source data, the final workbook, and non-identifiable aggregate outputs.

Raw VitalDB, MoVeR, and INSPIRE datasets are not redistributed.

This revision separates reference-missing time points from display-unavailable time points, reports both visible discordance directions and the unavailable-display component, adds repeated-measures agreement analyses, documents the predefined NIBP sample flow, and standardises the strategy phase convention.
