# 启动段质控重分析方案

日期 2026年10月7日

本版本用于核对疑似启动段技术异常对事件、输注调整和术后结局结果的影响。规则在本轮结局模型运行前固定。原始病例、轨迹和既往冻结版本全部保留。

## 证据和裁决状态

87例技术复核清单包含数字压力筛查或波形累计低值非脉动至少60秒的病例。已完成程序证据整理和AI辅助图形技术复核。本设计采用规则性信号质量敏感性分析，未实施独立医生临床裁决，也不把病例签署作为本版待完成的前提。真人作者复核关键方法、数值和稿件并承担责任，不等同于逐段建立临床裁定的参考标准。历史记录中的待裁决字段仅表示当时的候选方案状态。

## 固定比较

1. original 原冻结轨迹重算，须首先与已发表包中的数值核对。
2. qc60 在首次有效参考MAP后的600秒内，连续至少60秒满足MAP低于40 mmHg、波形有效覆盖至少80%、波形第5至95百分位幅度不超过5 mmHg的10秒区间置为缺测。只掩蔽满足条件的完整连续段，不扩展到其余低值或相邻恢复段。重新执行全麻醉窗有效参考覆盖至少80%的纳入门槛。
3. qc_all 同一启动窗口内所有满足上述逐10秒条件的区间置为缺测，不要求连续60秒；重新执行80%覆盖门槛。该分析检验更宽松的技术筛除范围。
4. startup10 排除首次有效参考MAP起600秒的全部参考及采样值。作为窗口敏感性保留原病例，不以被主动删去的窗口重新筛选病例。此分析包含真实早期低血压，不能解释为伪影校正。

qc60和qc_all均为规则性技术质控敏感性分析，阈值不是经验证的临床信号质量标准。没有波形的53例保留，不把波形缺失当作参考无效。完整原始时间轴保留，不插值，不重启采样相位，掩蔽值不可成为间断显示的采样源。原麻醉时长作为模型协变量和既定时间分母保留；若另报有效参考时间分母，必须明确标注。

## 统一重算

事件定义、采样间隔与相位、输注事件合并与稳定性、恢复判定、术后AKI和ICU结局定义、协变量及受试者聚类方法沿用原稿。变更参考后重新生成暴露和局部参考质量，不直接重用旧暴露。报告样本数、事件数、效应量和95%置信区间。核对病例排除的原因及所有分母，不以P值决定模型或清洗规则。
