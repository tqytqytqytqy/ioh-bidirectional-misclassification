# EJA Publication Wording Revision

Statistical estimates, event counts and model inputs are unchanged. Current publication labels distinguish observed low-pressure run end from the two-normal-bin confirmed recovery used in infusion analyses. Missing-data or recording endpoints contribute zero observed post-run persistence, not confirmed zero clinical persistence.

The early-adjustment exclusion is measured from analytic-window start without masking reference pressure; startup-window masking begins at first finite reference MAP. Current table and workbook labels and notes are aligned.

Independent physician clinical adjudication was not performed and is not a pending prerequisite. Historical audit values, clinical_adjudication_status fields and files prefixed legacy_ retain the earlier recorded scope; they are not current completion requirements.

Supplementary S1 is redrawn from its frozen aggregate source CSV, whose provenance was bound to the identical previous PNG. Supplementary S2 is regenerated from unchanged aggregate estimates. The new drawing changes only labels, units and interval punctuation. Main Figure 3 improves text contrast without changing geometry or values.
